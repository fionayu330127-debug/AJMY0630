# AI 视频混剪 — 架构说明（v2，已按摸底报告修订）

## 一、现状（摸底报告确认）
- 渲染已经是真实的：服务器 Node 进程调用 FFmpeg 完成分段、缩放、字幕修复、文案绘制、拼接、混音。
- 素材/成品元数据存于 modules/ai-video-system/data/store.json（folders、tags、materials、products、jobs），
  文件存于同目录 uploads、products、tmp。
- 任务在内存中运行，服务重启即丢失；没有重试、没有锁；store.json 并发写有覆盖风险。
- 已有能力可复用：字幕区域视觉识别与"中文字幕修复"、文案裂变（OpenAI 兼容接口）、
  音乐自动匹配的雏形、成品库。
- 缺口：缩略图与时长、音乐名称显示、成品库字段（duration/dur、size）、真实视频预览、
  素材与产品无关联、素材无片段级理解（只有大类标签）、无日语 TTS、无合规检查。
- 商品中心的商品数据在 TK 模块的 SQLite 里；主库 PostgreSQL 另有一张 products 表。
  两者与 AI 剪视频目前都没有关联，且都没有"卖点""价格"字段。
- Agent 中心是规则引擎，没有大模型调用与工具调用机制；"数据助手"为占位页。

## 二、目标架构
先在现有服务器内把能力做稳；算力不够时再把渲染拆到独立 worker（本机 Windows 主动拉任务）。

    浏览器 → ERP（Express）
               ├─ 素材/音乐/成品管理、产品档案
               ├─ 文案裂变、违禁词检查、素材匹配（调用 OpenAI 兼容接口）
               ├─ 任务队列（PostgreSQL：video_jobs，持久化，可恢复）
               └─ 渲染执行器（先在服务器内，限制并发；将来可替换为 worker）

执行器与队列之间保持接口分离，这样将来拆成 worker 时只替换执行器，不重写业务。
worker 协议见 WORKER_PROTOCOL.md（状态：暂缓，阶段 F 才可能启用）。

## 三、新增数据表（PostgreSQL，前缀 video_，只新增，可重复执行）
| 表 | 作用 |
|---|---|
| video_jobs | 任务：类型、状态、参数 JSON、进度、重试次数、错误、触发来源、原因、租约/心跳 |
| video_clips | 片段：所属素材、起止时间、描述、标签、向量、冲击力评分、是否停用 |
| video_product_profiles | 产品档案：产品引用、卖点、禁用词、目标人群、价格带、合规类别、素材文件夹 |
| video_outputs | 成品：文案、所用片段、BGM、时长、大小、封面、产品、版本号、是否使用 AI 配音 |
| video_feedback | 投放表现：播放、完播、点击、转化（阶段 E 之后） |
| video_banned_terms | 日语违禁词库，可编辑 |

素材与音乐元数据先继续用 store.json，待阶段 B 评估后再决定是否迁入 PostgreSQL。

## 四、阶段（每个阶段都走完整发布流程后再开始下一个）
| 阶段 | 内容 | 风险 |
|---|---|---|
| A | 修现有模块：素材缩略图与时长、音乐名称显示、成品库字段、真实 video 预览与封面、清理旧模拟函数 | 低 |
| B | 可靠性：任务持久化到 PostgreSQL、重启可恢复、渲染并发上限与 FFmpeg 超时、store.json 并发写保护、发布不覆盖 ai-video-system/data | 中 |
| C | 理解与匹配：切镜头、AI 打标签（复用 OPENAI_VISION_MODEL）、向量、按语义匹配；产品档案并绑定素材文件夹 | 中 |
| D | 出片：日语 TTS、字幕样式、复用中文字幕修复、BGM 情绪匹配与混音 | 中 |
| E | 合规与规模化：日语违禁词、去重、批量、换素材重混、反馈数据录入 | 中 |
| F | 视情况：渲染拆到独立 worker；Agent 化（脚本策划 Agent → 全流程 Agent，对外动作需人工确认） | 高 |

## 五、数据与发布安全
- modules/ai-video-system/data 是用户数据，必须确认发布脚本不会覆盖或删除它，
  且不进入 Git、必须有独立备份。
- 3002 测试使用的数据库必须与生产库区分，或确认只读测试。

## 六、合规提醒（日本站）
- 薬機法、景品表示法：避免绝对化与功效承诺用语（如"治る""最安""No.1"）
- BGM 授权需覆盖 TikTok 带货/广告场景
- TikTok 对 AI 生成内容（含 AI 配音）有披露要求，成品需记录是否使用 AI 配音
- 不使用模拟点击等非官方方式自动发布到 TikTok；发布环节保持人工确认
